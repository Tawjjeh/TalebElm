# Feature Specification: Center Management

## Status

Planned. The current codebase has no Center entity, persistence mapping, repository, service, DTO, or API endpoint.

## Scope

Define how learning centers are represented and managed. This feature is not implemented, and its domain and API contracts have not yet been decided.

## Contracts to Define

- Center fields, validation rules, and lifecycle.
- Repository and application-service responsibilities.
- API operations, request/response DTOs, and authorization.
- Relationships between a center and other platform concepts, if any.

All entity fields, relationships, and endpoint details are TBD and must be agreed before implementation. Do not treat this document as describing existing behavior.
