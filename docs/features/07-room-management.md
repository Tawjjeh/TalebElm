# Feature Specification: Room Management

## Status

Planned. The current codebase has no Room entity, persistence mapping, repository, service, DTO, or API endpoint.

## Scope

Define how rooms are represented and managed for the platform. This feature is not implemented, and its domain and API contracts have not yet been decided.

## Contracts to Define

- Room fields, validation rules, and lifecycle.
- Whether and how a room belongs to a center.
- Repository and application-service responsibilities.
- API operations, request/response DTOs, and authorization.

All entity fields, relationships, and endpoint details are TBD and must be agreed before implementation. Do not treat this document as describing existing behavior.
