# TalebElm Project Sustainability

> Status: Proposed.
> TalebElm is an independent open-source project licensed under GNU General Public License v3.0 (GPL-3.0). Nothing in this document is decided or active today.

## Principles

1. **Free Core Education:** The curriculum, learning paths, practice problems, and public Resource Hub will always remain 100% free under GPL-3.0.
2. **No Pay-to-Win Gating:** Progression unlocking, exams, and verified problem completion will never require payment.
3. **Community Ownership:** Code, documentation, and curricula belong to the community under public version control.
4. **Transparency:** If financial contributions or sponsorships are accepted in the future, allocations and expenses will be reported publicly.

## Options Under Exploration (All Proposed)

- **Community Sponsorships & Donations:** Individual donations via GitHub Sponsors, Open Collective, or Polar without private features or code advantages.
- **Infrastructure Partnerships & Grants:** Non-profit cloud hosting credits or developer grants (such as Azure, AWS, or Cloudflare) to offset server and CI compute costs.
- **Hiring Partnerships:** Optional, opt-in employer partnerships connecting verified graduates to software engineering roles.
- **Optional Supplementary Mentorship:** Optional one-on-one code reviews for learners who request human feedback, completely detached from progression.

## Current Status

No monetization or financial instruments are active or planned for the MVP. Any future sustainability model will be evaluated openly with the community before adoption.
