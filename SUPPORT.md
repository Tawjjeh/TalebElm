# Support

- **Question about the project, or an idea you want to discuss?** Open a thread in [Discussions](https://github.com/Tawjjeh/TalebElm/discussions). Issues are for work that needs code or a document change.
- **Found a bug or a wrong document?** Open an issue with the template that fits. Say what you did, what you expected, and what happened, and paste the error text instead of a screenshot of it.
- **Want to work on something?** Read [CONTRIBUTING.md](CONTRIBUTING.md) first. An issue is open for work once it has `help wanted` and you are assigned to it.
- **Found a security problem?** Do not open a public issue. Follow [SECURITY.md](SECURITY.md).

This is a volunteer project, so answers take the time they take. A clear reproduction usually gets one quickly.
